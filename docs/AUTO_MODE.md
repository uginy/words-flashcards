# Авто-режим для изучения карточек

## Что это?

Авто-режим автоматически воспроизводит карточки: озвучивает слово на иврите, затем перевод на русский, и переходит к следующей карточке. Идеально для пассивного прослушивания.

## Как использовать

1. Откройте раздел **"Учить"**
2. Нажмите **"▶️ Авто-режим"** вверху экрана
3. Для остановки нажмите **"⏸️ Стоп"**

## Настройки

В разделе **Настройки → Авто-режим** можно настроить:
- **Задержка после иврита** (по умолчанию 1500 мс)
- **Задержка после русского** (по умолчанию 2000 мс)
- **Задержка перед следующей карточкой** (по умолчанию 1000 мс)

## Особенности

✅ Статистика НЕ обновляется (режим только для прослушивания)
✅ Позиция сохраняется после рефреша страницы
✅ Циклическое воспроизведение (после последней → первая)
✅ Кнопки управления заблокированы во время воспроизведения
