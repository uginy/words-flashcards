# LM Studio Integration

## Обзор

Добавлена полная поддержка LM Studio в качестве провайдера LLM для обработки слов на иврите.

## Что было добавлено

### 1. Конфигурация
- `src/config/lmstudio.ts` - конфигурация по умолчанию для LM Studio
  - URL по умолчанию: `http://localhost:1234/v1`
  - Модель по умолчанию: `local-model`
  - Рекомендуемые модели для работы с ивритом

### 2. Сервисы
Создана полная структура сервисов в `src/services/lmstudio/`:
- `api-client.ts` - клиент для работы с LM Studio API (OpenAI-совместимый)
- `enrichment.ts` - обогащение слов (перевод, транскрипция, категории, спряжения)
- `prompts.ts` - промпты для различных моделей
- `processors.ts` - обработка ответов от LLM
- `word-suggestions.ts` - генерация предложений слов по категориям и уровням
- `index.ts` - главный экспортный файл

### 3. Интеграция в приложение
- `src/store/wordsStore.ts` - добавлена поддержка LM Studio в:
  - Валидация настроек провайдера
  - Обработка слов в фоновом режиме
  - Обогащение слов через LM Studio API
- `src/services/wordSuggestions.ts` - добавлена поддержка LM Studio для генерации предложений слов

### 4. UI компоненты
Компоненты уже поддерживали LM Studio:
- `src/components/WordInput.tsx` - отображение статуса LM Studio
- `src/components/Settings.tsx` - настройки LM Studio (URL, модель)

## Как использовать

1. Запустите LM Studio локально на порту 1234
2. Загрузите модель в LM Studio
3. В настройках приложения:
   - Перейдите в раздел "ИИ Модель"
   - Выберите вкладку "LM Studio"
   - Укажите URL (по умолчанию `http://localhost:1234/v1`)
   - Выберите модель из списка доступных
   - Сохраните настройки
4. Переключитесь на провайдер "LM Studio" в настройках
5. Теперь можно добавлять слова - они будут обрабатываться через LM Studio

## API совместимость

LM Studio использует OpenAI-совместимый API:
- Endpoint: `/v1/chat/completions`
- Формат запроса: OpenAI Chat Completions API
- Поддержка JSON mode через `response_format: { type: 'json_object' }`

## Отличия от других провайдеров

### OpenRouter
- Требует API ключ и интернет
- Поддерживает множество моделей
- Имеет функцию refinement (уточнение перевода)
- Поддерживает перевод с русского на иврит

### Ollama
- Локальный провайдер
- Использует собственный API формат
- Не требует API ключ

### LM Studio
- Локальный провайдер
- Использует OpenAI-совместимый API
- Не требует API ключ
- Удобный UI для управления моделями

## Ограничения

На данный момент LM Studio поддерживает:
- ✅ Обогащение слов (перевод, транскрипция, категории, спряжения)
- ✅ Генерация предложений слов
- ✅ Фоновая обработка слов
- ❌ Refinement (уточнение перевода) - доступно только для OpenRouter
- ❌ Перевод с русского на иврит - доступно только для OpenRouter

## Рекомендуемые модели

Для работы с ивритом рекомендуются:
- `gemma-2-9b` - высокое качество обработки иврита
- `llama-3.2-3b` - быстрая обработка, базовое качество
- `qwen2.5-7b` - альтернативный вариант

## Troubleshooting

### LM Studio недоступен
- Убедитесь, что LM Studio запущен
- Проверьте, что сервер запущен на правильном порту (по умолчанию 1234)
- Проверьте URL в настройках

### Модель не найдена
- Убедитесь, что модель загружена в LM Studio
- Проверьте имя модели в настройках
- Обновите список моделей в настройках

### Плохое качество перевода
- Попробуйте другую модель
- Увеличьте размер модели (например, с 3B на 7B или 9B)
- Проверьте, что модель поддерживает иврит
